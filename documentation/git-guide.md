# GIT COMMIT MESSAGE CONVENTION

1. **Fix:** 
   > When fixing bugs.
   * **Example:** `Fix: Fixed onClick event in submit button of login form. Reason: user could spam it infinitely.`

2. **Feat:** 
   > When adding new feature.
   * **Example:** `Feat: Added new functionality for theme switching.`

3. **Style:** 
   > When altering/adding css style in any component.
   * **Example:** `Style: Centered a div in the main content area of dashboard.`

4. **Change:** 
   > When refactoring/changing a feature/function/logic.
   * **Example:** `Change: Altered module.dto properties. Reason: Match naming convention for backend.`

5. **Migration:** 
   > When adding a new model for database.
   * **Example:** `Migration: Added a new property <Propertie's name> in User Model`

6. **Remove:** 
   > When removing redundant code or cleanup debuggers/console.logs.
   * **Example:** `Remove: Cleanup Debuggers`
