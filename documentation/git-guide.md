# GIT COMMIT MESSAGE CONVENTION

1. Fix: <!--- When fixing bugs, example: Fix: Fixed onClick event in submit button of login form. Reason: user could spam it infinitely. --->
2. Feat: <!--- When adding new feature, example: Feat: Added new functionality for theme switching.>
3. Style: <!--- When altering/adding css style in any component, example: Style: Centered a div in the main content area of dashboard. --->
4. Change: <!--- When refactoring/changing a feature/function/logic, example: Change: Altered module.dto properties. Reason: Match naming convention for backend. --->
5. Migration: <!--- When adding a new model for database, example: Migration: Added a new property <Propertie's name> in User Model --->
6. Remove: <!--- When removing redundant code or cleanup debuggers/console.logs, example: Remove: Cleanup Debuggers --->
